# 📖 Project Overview

This project combines modern web technologies with Generative AI to streamline the content creation process.

The application features a lightweight frontend built with **HTML, CSS, and JavaScript**, while the backend leverages **Node.js**, **Express.js**, and **MongoDB Atlas** for secure data management.

Administrators can generate AI-powered articles, review content, and publish them instantly through a protected dashboard.

# ⚙️ Local Installation

## Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/YOUR_REPOSITORY.git

cd YOUR_REPOSITORY
```

## Install Dependencies

```bash
cd backend

npm install
```

---

# 🔐 Environment Variables

Create a `.env` file inside the **backend/** directory.

```env
MONGO_URI=your_mongodb_connection_string

GEMINI_API_KEY=your_google_gemini_api_key

ADMIN_PASSWORD=your_secure_password

ADMIN_ROUTE=/your_secret_admin_route

PORT=5000
```

---

# ▶️ Run the Application

```bash
cd backend

node server.js
```

Server will start on

```
http://localhost:5000
```

## 📖 Overview

An end-to-end **AI-powered content management platform** that enables administrators to generate, edit, store, and publish articles using **Google Gemini AI**. The application is backed by a **cloud-hosted MongoDB Atlas database**, ensuring persistent storage, efficient data retrieval, and scalable content management.

Built with a lightweight frontend and a robust Node.js/Express backend, this project demonstrates practical experience in **Full-Stack Development, RESTful APIs, AI Integration, Cloud Databases, CRUD Operations, and Production Deployment.**
